# CJ-Switcher для Windows

Маленькая программа (около 2 МБ, один exe): исправляет слова, набранные в неправильной раскладке (EN/RU).
Работает на Windows 10 (версия 1803 и новее) и Windows 11. Ничего устанавливать не нужно.

## Как собрать
1. Положите `en.txt` и `ru.txt` (те же, что в проекте для Mac) в папку `Dictionaries/`.
2. Загрузите проект на GitHub (новый репозиторий, можно приватный).
3. Вкладка Actions → Build Windows → Run workflow.
4. Через 2–3 минуты внизу страницы запуска появится файл `CJ-Switcher-Windows`: скачайте, распакуйте, внутри `CJ-Switcher.exe`.

## Как пользоваться
- Значок появляется в области уведомлений (трее), возможно, за стрелкой «^». Меню по правой кнопке мыши.
- Автозамена: набрали слово в неправильной раскладке и нажали пробел, слово исправится.
- Ctrl+Alt+D: выделенное слово переводится в другую раскладку и добавляется в свои слова.
- Ctrl+Alt+Z: отменить последнее добавленное слово.
- В IDE и терминалах автозамена выключена.
- Свои слова: `%APPDATA%\CJ-Switcher\custom-words.json`. Журнал ошибок: `%APPDATA%\CJ-Switcher\log.txt`.

## Ограничения
- В окнах, запущенных от имени администратора, программа не работает, если сама не запущена от администратора.
- Первый запуск: SmartScreen может предупредить («Подробнее → Выполнить в любом случае»).
- Проверка детектора: `CJ-Switcher.exe --selftest` (итог также в `%TEMP%\cj-switcher-selftest.txt`).
